REA SHORT DRAMA STUDIO

Windows 실행
1. 이 폴더의 「실행하기.bat」을 더블클릭합니다.
2. 또는 바탕화면 REA 폴더의 「REA 숏드라마 스튜디오」 바로가기를 실행합니다.

주의
- index.html은 실행 파일이 아닙니다. 브라우저에서 열면 실행 안내만 표시됩니다.
- release\win-unpacked 폴더를 이동하거나 삭제하지 마세요. 앱 실행에 필요한 파일이 들어 있습니다.

기본 작업 순서
1. 작품 기획
2. 에피소드
3. 대본 작성 후 「장면으로 나누기」
4. 캐릭터
5. 스토리보드
6. 미리보기 및 WebM 저장

앱은 오프라인으로 작동하며 프로젝트는 이 PC에 자동 저장됩니다.
