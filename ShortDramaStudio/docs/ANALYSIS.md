# Higgsfield Short Drama Studio 구조 분석 → REA 클론 설계

> 작성일: 2026-11-23 · 분석 기준: Higgsfield( higgsfield.ai ) 공개 UI/기능 소개 기준.
> 실제 제품은 로그인·크레딧 과금·클라우드 생성 방식이라 내부를 직접 관측할 수 없어,
> 공개된 화면 구조와 기능 흐름을 기준으로 **동작 방식이 같은 로컬 클론**을 설계했다.
> ※ 요청의 "참고 이미지"가 첨부되지 않아 공개 UI 스타일(다크 시네마틱 + 퍼플 그라디언트)을 기준으로 고정함.

---

## 1. 원본(Higgsfield Short Drama Studio) 구조 추정

Higgsfield는 시네마틱 카메라 모션 프리셋(크래시 줌, 달리, 스냅 팬 등)이 시그니처인
AI 영상 생성 플랫폼이고, Short Drama Studio는 그 위에서 **숏폼 드라마(세로형 짧은 드라마)**를
"캐릭터 → 대본 → 장면/샷 분해 → 샷별 생성 → 편집 → 렌더" 흐름으로 만드는 스튜디오다.

### 1.1 모듈 흐름도

```
[작품 대시보드]
    ↓ 새 드라마
[포맷 설정] 종횡비(9:16 등) · 시각 스타일 프리셋
    ↓
[캐릭터 스튜디오] 등장인물 프로필 + 얼굴/의상 일관성 고정
    ↓
[대본] 로그라인 → 에피소드 → 장면(INT/EXT·장소·시간) → 지문+대사
    ↓
[샷 분해·스토리보드] 장면을 샷으로 쪼개고 각 샷에 프레임(이미지) 배정
    ↓
[카메라 모션] 샷마다 모션 프리셋(줌·팬·달리·핸드헬드…) + 길이 지정
    ↓
[프리뷰 플레이어] 타임라인 재생, 자막/타이틀, BGM
    ↓
[렌더·내보내기] 영상 파일로 출력 (원본은 크레딧 소모)
```

### 1.2 원본의 제약 (클론에서 제거할 것)

| 원본 제약 | REA 클론의 대응 |
|---|---|
| 크레딧 과금 (유료) | 생성 요소 전부 무료화: 절차적 스토리보드 아트 + 사용자 이미지 |
| 클라우드 전용, 오프라인 불가 | 100% 로컬 실행, 네트워크 호출 0건 |
| 워터마크/요금제별 제한 | 제한 없음 — 무제한 렌더 |
| 광고/업셀 모달 | 광고 없음 |
| AI 생성 대기열 | 즉시 생성(수학적 모션 시뮬레이션) |

### 1.3 "AI 생성"을 무료로 대체하는 전략

원본의 가치 = ①그림 생성 ②카메라 모션 ③일관된 캐릭터 ④빠른 편집.
REA는 다음처럼 동등한 결과를 로컬에서 만든다:

1. **프레임**: 사용자 이미지 업로드 OR 절차적 스토리보드 아트(팔레트 그라디언트+글로우+그레인 캔버스 생성)
2. **카메라 모션**: 정지 이미지에 수학적 변환(스케일/이동/회전+이징)을 적용해 실제 움직임처럼 렌더 — 원본의 시그니처를 그대로 재현
3. **캐릭터 일관성**: 캐릭터 프로필(이모지/색/사진)이 자막·대사·스토리보드 아트에 일관 적용
4. **편집**: 장면→샷 트리, 순서 변경, 시간 조절, 즉시 프리뷰
5. **렌더**: Canvas `captureStream` + `MediaRecorder`로 실제 **.webm 영상** 무제한 출력 (BGM 파일 믹싱 지원)

## 2. REA Short Drama Studio 모듈 매핑 (8개)

| # | 모듈 | 원본 대응 | 구현 위치 |
|---|---|---|---|
| 1 | 프로젝트 매니저 | 작품 대시보드 | 홈 뷰 — 프로젝트 CRUD, 샘플, JSON 가져오기 |
| 2 | 포맷·스타일 | 종횡비/스타일 프리셋 | 9:16·16:9·1:1·2.35:1 + 팔레트 6종 |
| 3 | 캐릭터 스튜디오 | 일관성 캐릭터 | 이모지·색·사진·역할·노트, 대사/자막에 자동 반영 |
| 4 | 대본 편집기 | 대본 | 에피소드→장면(INT/EXT·장소·시간·지문)→샷·대사 트리 |
| 5 | 스토리보드 | 샷 분해·프레임 | 샷 카드 그리드, 프레임 자동생성, 업로드, 재정렬, 인스펙터 |
| 6 | 카메라 모션 엔진 | 모션 프리셋 | 12종 프리셋(데이터 기반), 이징·핸드헬드 노이즈 포함 |
| 7 | 프리뷰 플레이어 | 타임라인 프리뷰 | 캔버스 재생/일시정지/시크, 자막·타이틀카드·그레인·BGM |
| 8 | 렌더·내보내기 | 영상 출력 | .webm 무제한 렌더, JSON 백업, 대본 TXT, 단독재생 HTML |

## 3. 데이터 모델

```
Project ─ title, genre, aspect(9:16|16:9|1:1|2.35:1), palette
        ├ characters[] ─ name, role, emoji, color, note, photo?
        └ episodes[] ─ title, logline
            └ scenes[] ─ slug(INT./EXT.), loc, time, action
                └ shots[] ─ desc, motion(12종), dur(초), tint, img(dataURL), dialogues[] ─ charId, line
```

- 저장: `localStorage` 자동 저장(800ms 디바운스) + JSON 파일 백업/복원
- 이미지: 업로드 시 최장변 1280px로 축소·JPEG 압축 후 dataURL 저장 (할당량 보호)
