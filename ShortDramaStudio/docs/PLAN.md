# REA Short Drama Studio — 개발 PLAN (목차·우선순위·숫자목표·끝조건)

> 요구사항: 무료 · 광고 없음 · 무제한 · 독립실행 · 바탕화면 REA 폴더.
> 진행 규칙: 목차 먼저 → 작은 단위 단계별 확장 → 각 단계 스크린샷 끝조건 통과 → 화면 비평가 루프(수정 최대 5라운드, 신규 이슈 0까지) → 질문 없이 완성.

## 0. 고정 스타일 스펙 (먼저 확정 — 이후 변경 금지)

Higgsfield 계열 다크 시네마틱 스타일. 디자인 토큰(21종)을 아래로 고정하고 CSS 변수로 구현.

| 토큰 | 값 |
|---|---|
| bg / bg2 | `#0a0a0f` / `#0f0f16` |
| panel / panel2 / elev | `#14141d` / `#1a1a26` / `#20202e` |
| line / line2 | `rgba(255,255,255,.08)` / `.14` |
| text / text2 / text3 | `#f2f2f7` / `#a1a1b5` / `#6b6b80` |
| accent(그라디언트) | `#8b5cf6 → #d946ef` (135deg) |
| sub-accent / ok / warn / danger | `#22d3ee` / `#34d399` / `#fbbf24` / `#f43f5e` |
| radius | 8 / 12 / 16 / 22px |
| shadow | `0 10px 30px rgba(0,0,0,.45)` |
| 폰트 | 시스템 스택(오프라인): 'Segoe UI', 'Malgun Gothic' + 표시용 weight 800, letter-spacing -0.02em |
| 시그니처 질감 | 전역 필름 그레인(SVG feTurbulence, opacity≈.03) + 라일 글로우 |
| 레이아웃 | 좌측 아이콘 레일(64px) + 상단바(56px) + 본문. 카드 그리드, 우측 인스펙터 |

## 3. 스크린샷 체크포인트 정의 (끝조건의 판정 대상)

| ID | 화면 상태 |
|---|---|
| S0 | 앱 셸 (홈 빈 상태 전) — 스타일 고정 판정 |
| S1 | 홈 — 샘플 프로젝트 카드 그리드 |
| S2 | 캐릭터 스튜디오 — 카드 + 편집 모달 |
| S3 | 대본 편집기 — 장면 트리 + 대사 편집 |
| S4 | 스토리보드 — 샷 그리드 + 우측 인스펙터 |
| S5 | 플레이어 — 재생 중 프레임 + 타임라인 스트립 |
| S6 | 내보내기 — 4종 카드 |
| S7 | 새 프로젝트 모달 |

**전체 끝조건(모든 스크린샷 공통)**: ① 레이아웃 깨짐 0 ② 텍스트 잘림/겹침 0 ③ 비활성(죽은) 컨트롤 0 ④ 다크 테마 대비 가독성 통과 ⑤ 비평가 라운드에서 신규 차단 이슈 0.

## 4. 화면 비평가 루프 규칙

1. 스크린샷 S0~S7 촬영 (로컬 브라우저 자동화).
2. 독립 비평가(서브 에이전트) + 자체 비평 2중 판정: 레이아웃/가독성/일관성/빈 컨트롤.
3. 이슈 → 수정 → 해당 화면 재촬영. **1라운드 = 1회 비평+수정 사이클, 최대 5라운드.**
4. 라운드에서 신규 차단 이슈가 0이 나오면 즉시 종료 (성공).
5. 모든 라운드 기록은 QA_LOG.md에 남긴다.
