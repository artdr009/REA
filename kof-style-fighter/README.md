# IGNITION FIGHTERS

KOF(킹 오브 파이터즈) 스타일의 2D 대전 격투 게임입니다. **기존 게임의 코드·그래픽·캐릭터를 복사하지 않고** 게임플레이 스타일만 참고해 처음부터 새로 만든 오리지널 구현입니다 (HTML5 Canvas + 순수 JavaScript, 이미지/오디오 파일 0개 — 모든 그래픽과 사운드는 코드로 실시간 생성).

## 실행 방법

1. `index.html`을 더블클릭해서 브라우저(Chrome/Edge 권장)로 열면 바로 실행됩니다.
   - 빌드/설치 과정 없음
2. 소리가 나오지 않으면 게임 중 아무 키나 한 번 눌러주세요 (브라우저 정책상 첫 입력 후 오디오 활성화).
3. 창이 어두워 보이면 화면을 클릭한 뒤 키보드로 조작하세요.

## 조작법

| 동작 | 1P | 2P |
|---|---|---|
| 이동 / 앉기 | `W A S D` | `← ↑ ↓ →` |
| 점프 | `W`(방향키 조합 시 8방향 점프) | `↑` |
| 약주먹 | `U` | `Num 1` |
| 강주먹 | `I` | `Num 2` |
| 약발 | `O` | `Num 3` |
| 강발 | `P` | `Num 0` (또는 `Num Enter`) |
| 가드 | 뒤로 걷기(후퇴 키 홀드), 아래+후퇴 = 앉아 가드 | 동일 |
| 일시정지 | `Esc` | `Esc` |
| 음소거 | `M` | `M` |

- **하단 공격**(앉아 약K, 발 걸기)은 **앉아 가드**로만 막을 수 있습니다.
- 공중 공격은 한 번의 점프에 한 번만 사용할 수 있습니다.

## 캐릭터 & 기술 커맨드

### 하염 (HAYEOM) — 불꽃의 격투가
| 기술 | 커맨드 |
|---|---|
| 화염탄 (투사체) | ↓ ↔ ↘ → (↓↘→) + 주먹 |
| 상승열격 (대공기, 무적) | → ↓ ↘ (→↓↘) + 발 |
| 초필살기 · 염룡폭 | ↓↘→ ↓↘→ + 주먹 (게이지 50%) |

### 가람 (GARAM) — 바람의 검사
| 기술 | 커맨드 |
|---|---|
| 선풍참 (돌진 2연타) | ↓ ↙ ← (↓↙←) + 주먹 |
| 회오리파 (큰 투사체) | ↓↘→ + 발 |
| 초필살기 · 폭풍연무 (5연타 돌진) | ↓↘→ ↓↘→ + 발 (게이지 50%) |

커맨드는 방향키를 순서대로 누른 뒤 공격 버튼을 누르면 발동합니다 (입력 버퍼 약 0.5초).

## 게임 시스템

- **규칙**: 2선승제, 라운드당 99초. 시간 종료 시 체력이 많은 쪽 승리.
- **파워 게이지**: 때리면 소폭, 맞으면 크게 충전. 50% 이상이면 초필살기 사용 가능 (`SUPER OK` 표시).
- **콤보**: 약공격이 맞은 뒤 강공격/필살기로 캔슬 가능. 연속 히트일수록 데미지가 점점 감소.
- **가드**: 가드해도 카드 데미지(칩 데미지)가 조금 들어갑니다.
- **승리 연출**: K.O. 슬로모션, PERFECT 표시, 승자 포즈 등.

## 프로젝트 구조

```
kof-style-fighter/
├── index.html
├── css/style.css
└── js/
    ├── config.js      # 전역 상수(물리/프레임/키 매핑)
    ├── utils.js       # 수학·판정·텍스트 유틸
    ├── input.js       # 키보드 + 필살기 커맨드 입력 버퍼
    ├── audio.js       # WebAudio 실시간 합성 SFX/BGM
    ├── characters.js  # 캐릭터 2명의 기술 프레임데이터
    ├── fighter.js     # 파이터 상태머신·물리·히트 처리
    ├── effects.js     # 파티클 이펙트 + 투사체
    ├── renderer.js    # 절차적 그래픽(무대/캐릭터/HUD)
    ├── ai.js          # CPU (쉬움/보통/어려움)
    ├── match.js       # 라운드/KO/타이머/카메라
    ├── screens.js     # 타이틀/모드/캐릭터선택/VS/결과
    └── main.js        # 상태 전환 + 60FPS 게임 루프
```

## 구현 범위 / 한계

- 1인 vs CPU(난이도 3단계) + 같은 키보드 2인 대전
- 약/강 공격, 8방향 점프, 하단 공격, 가드, 캔슬 콤보, 투사체 상쇄, 히트스톱/화면 흔들림
- 2명의 오리지널 캐릭터, 커맨드 필살기, 초필살기
- 네트워크 대전, 저장 기능, 추가 캐릭터는 미구현 (구조상 `characters.js`에 데이터를 추가하면 확장 가능)

## 저작권 안내

이 프로젝트는 SNK의 《킹 오브 파이터즈》와 무관한 학습용 오리지널 팬 프로젝트입니다. 원작의 코드, 이미지, 음악, 캐릭터(키오, 이오리 등)를 일절 사용하지 않았으며, 2D 대전 격투라는 장르적 관습(라운드제, 커맨드 입력, 게이지 등)만 참고했습니다.
